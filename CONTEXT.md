# Markdown Preview Navigation

This context describes the document navigation concepts added to VS Code's Markdown preview.

## Language

**Floating TOC**:
A movable table of contents that represents the headings in the current Markdown preview and indicates the reader's current section.
_Avoid_: Sidebar, navigation panel

**Document Heading**:
A titled section in the Markdown preview that can be targeted by the Floating TOC.
_Avoid_: TOC item, menu item

**Active Heading**:
The Document Heading corresponding to the reader's current scroll position.
_Avoid_: Selected item, highlighted link
