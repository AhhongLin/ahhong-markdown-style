
# ahhong-markdown-style

markdown style 自訂專案，提供 h1, h2, h3 格式

## 打包指令

執行以下指令進行打包，產生可安裝的 VS Code 擴充套件檔案：

```bash
vsce package
```

打包後會產生 `.vsix` 檔案，可用於 VS Code 安裝。

## 使用說明

1. 在 VS Code 中安裝本擴充套件。
2. 重新啟動 VS Code。
3. 即可套用 ahhong 專屬 keymap。
